Building models

m2n2 builds a model with MixedModelNN.from_dataframe(), from a pandas DataFrame and one or several PyTorch networks.

The from_dataframe constructor

model = MixedModelNN.from_dataframe(
    data      = data,
    response  = "DTF1",
    fixed     = "1 + country",
    embedding = {
        "geno": Embedding(
            network,
            optimizer = partial(
                torch.optim.AdamW,
                lr = 1e-3,
                weight_decay = 1e-1
            )
        ),
    },
    random = [
        RandomNN(
            embedding = "geno"
        ),
        RandomNN(
            embedding = "geno",
            group = "country"
        ),
    ],
    residual  = Residual(),
    lr_beta   = 1e-2,
    lr_var    = 1e-2,
)

model.fit()
Argument Meaning
data One row per individual.
response One response column.
fixed A patsy formula for \(X\). Defaults to the intercept "1".
embedding The networks, as a dictionary of named Embedding.
random The random effects, a list of RandomNN and pyreml Random terms.
residual The residual, a pyreml Residual. Defaults to Residual(): \(\sigma^2_R I\).
lr_beta Learning rate of \(\beta\). Defaults to 1e-3.
lr_var Learning rate of the variances. Defaults to 1e-3.

Embeddings

An Embedding wraps a network and its optimizer:

Embedding(
    network,
    optimizer = partial(torch.optim.AdamW, lr=1e-3, weight_decay=1e-1),
)
Argument Meaning
network The network \(\nu\), an nn.Module returning the embeddings (see the network).
optimizer A torch.optim optimizer, LBFGS excepted, as a factory of the parameter groups. Defaults to partial(torch.optim.AdamW, lr=1e-3, weight_decay=1e-1).

Its name in embedding is the handle by which the random effects refer to it. Several random effects can share the same embedding: the network is then embedded once per minibatch, and stepped once by its optimizer.

The network

The network is user-defined, under the following contract:

  • network() returns the \(n \times d\) embedding of every row of data, in the same order.
  • network(rows), with rows a boolean mask over the rows of data, returns the embeddings of the selected rows only. Training feeds the labelled rows of each minibatch alone, so that batch statistics (e.g. BatchNorm) never see the others.
  • The networks must share their device. The mixed model runs in double on that device; the networks keep their own dtype.

The features \(z\) are typically stored in the network as a buffer:

class Network(nn.Module):
    def __init__(self, z):
        super().__init__()
        self.register_buffer("z", z)
        self.body = nn.Sequential(...)

    def forward(self, rows=None):
        return self.body(self.z if rows is None else self.z[rows])

Different embeddings can read the same features, or different ones, e.g. SNPs and gene expressions.

The embeddings are projected on the unit sphere before entering the mixed model (see Deep kernel). Dropout and BatchNorm belong to the network: m2n2 switches it to train() mode for the gradient steps, and to eval() mode for validation and prediction.

Neural random effects

A RandomNN term is a random effect \(Z_j u_j\) built upon an embedding:

RandomNN(
    embedding = "geno",
    group     = None,
)
Argument Meaning
embedding Name of the embedding, a key of the embedding dictionary.
group Qualitative column defining the \(q_j\) groups of the term. Defaults to None: a single group, the general effect.

With \(Z = \nu(z, \theta)\) the embedding, the term reads:

  • \(Z_j = \bigoplus_{k=1}^{q_j} \nu(z_{(k)}, \theta)\), of dimension \(n \times q_j d\): the embedding of each individual in the columns of its group, zeros elsewhere;
  • \(u_j \sim N(0, \sigma^2_{u_j} I)\), \(u_j \in \mathbb{R}^{q_j d}\): one embedding effect vector per group.

Without group, \(Z_j = Z\): the effects \(u_j\) are shared by all individuals. With group, each group receives its own effects: combined with a general term on the same embedding, they capture what is specific to the group (see Deep kernel). The terms are independent: several groupings, crossed or nested, are as many terms.

Other random effects

Any pyreml Random term, e.g. a pedigree or an environmental effect, can be added to random, as well as any Residual structure. They follow the pyreml specification system, and their design is fixed during training.

Data layout and missing values

  • A row missing the response is left out of the fit, but still predicted.
  • A row missing a fixed covariate is left out of the fit.
  • group must be qualitative and complete: numeric codes are to be cast to str.

The random design \([Z_1 \mid Z_2 \mid \dots]\) has \(\sum_j q_j d_j\) columns over the RandomNN terms, plus those of the Random terms.

Optimizers

All variances are log-parameterized, and initialized by .fit() (see Initialization). The optimizer of each embedding is called on two parameter groups, and \(\beta\) and the variances are stepped by Adam:

Group Parameters Optimizer Weight decay Learning rate
Network weights Tensors of dimension \(\geq 2\) optimizer optimizer optimizer
Network biases, normalization parameters Vectors optimizer 0 optimizer
Fixed effects \(\beta\) Adam 0 lr_beta
Variances \(\log \sigma^2\) Adam 0 lr_var

The fitted model

After .fit() (see Training models):

Accessor Content
model.estimates Fixed-effect estimates (BLUE) as a long table response · term · estimate · SE · t.
model.residual The pyreml Residual: .residuals and .table of the labelled rows, .variance.
model.varcomp() Raw and unit variances, one row per term and the residual last (see Deep kernel).
model.loss, model.score Training curves (see Monitoring).
model.plot() Plot of the training curves, returns the figure (see Monitoring).
model.convergence Whether the REML of the polish converged, None with full_REML = False (see Polish).
model.random[j] The \(j\)-th random effect, in the order of random.

Each RandomNN term exposes:

Accessor Content
.prediction \(Z_j \hat u_j\) for every row of data, missing responses included.
.uhat \(\hat u_j\), of shape (q_j, d), one row per level of .levels.
.levels The levels of group, [None] without it.
.PEV Prediction error variance of \(\hat u_j\).
.pca PCA of the embeddings "Z" and of the weighted embeddings "Z*u", \(Z \odot \hat u_{j,k(i)}\), with \(k(i)\) the group of individual \(i\): coords, inertia, eigvec per embedding.
.plot(plan=(0, 1), group_by=None) Individual projections on the principal plan plan, colored by group_by, a qualitative column of data. Defaults to the term’s group, monochrome without it.

The Random terms expose their pyreml accessors.
